Features

Explore the powerful feature categories included in EJ_Core.

Chat System

Customizable chat format with LuckPerms prefix, hover effects, click actions, mentions, anti-spam, and blocked words filtering.

Spawn System

Create multiple spawn points with custom GUI menus, forced spawn on join, and teleport delays with boss bar support.

Homes

Players can set up to 100 homes with permission-based limits. Beautiful GUI for managing, teleporting, and deleting homes.

Warps

Server-wide warp locations with customizable icons and slots in an intuitive teleportation menu.

TPA

Full TPA and TPAHere system with auto-accept, accept menu, and per-player settings for teleport requests.

Economy Integration

Combat System

Combat tagging with boss bar timer, blocked commands during combat, kill messages, and customizable combat duration.

AFK System

Broadcasts

Timed announcements with custom messages, titles, action bars, and sounds. Multiple broadcast schedules supported.

Staff Tools

Admin Utilities

Anti Exploit

Installation

Follow these simple steps to get EJ_Core running on your server.

Step 1

Download the latest EJ_Core.jar file from the official resource page.

Step 2

Place the JAR file into your server's plugins folder.

Step 3

Restart your server or use a plugin manager to load EJ_Core.

Step 4

Configure the plugin by editing the config.yml and messages.yml files to your liking.

Requirements

EJ_Core requires Paper 1.21+ (or Purpur). Folia is fully supported. Java 21 is required. Soft dependencies include PlaceholderAPI, LuckPerms, Vault, ProtocolLib, PacketEvents, and Simple Voice Chat—all optional but recommended for full functionality.

Commands Overview

EJ_Core provides a comprehensive set of commands for players and administrators.

All commands are fully documented with usage information accessible in-game. The main administrative command is /ej_core (aliases: /ejc) which provides access to reload, economy management, spawn and warp administration, inventory viewing, crash testing, and more.

Player commands include /home, /spawn, /warp, /tpa, /msg, /pay, /balance, /stats, /settings, /ping, /report, and many others—all with intuitive tab completion and comprehensive feedback messages.

Permissions Overview

EJ_Core uses a straightforward permission system for access control.

The primary permission node is ejcore.admin which grants full access to all administrative features. Additional permissions include ejcore.fly, ejcore.repair, ejcore.doublejump, and ejcore.home.limit.<N> for granular control over player capabilities.

All permissions are documented in the plugin.yml file and can be managed through any permissions plugin such as LuckPerms.
