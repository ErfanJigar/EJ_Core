About EJ_Core

EJ_Core is a meticulously engineered core plugin designed for Minecraft server owners who demand reliability, performance, and a unified administrative experience. It replaces dozens of fragmented plugins with a single cohesive system, offering everything from teleportation and economy to advanced anti‑cheat and GUI menus. Built for Paper, Spigot, and Folia with seamless integration into the modern Minecraft ecosystem.

Installation

  1. Purchase and download EJ_Core from BuiltByBit.
  2. Place the EJ_Core.jar file into your server's /plugins folder.
  3. Restart your server (or use a plugin manager).
  4. Edit the generated configuration files inside /plugins/EJ_Core/ to suit your needs.
  5. Reload the plugin with /ej_core reload or restart the server.

Getting Started

After installation, configure the core settings in config.yml. Enable the features you want, set up spawn points, warps, and permissions. Use /ej_core reload to apply changes instantly. Explore the Settings Menu via /settings to personalize player experience.
