# 🚀 EJ_Core

**EJ_Core** is a powerful all-in-one Minecraft core plugin made for modern servers.  
It includes everything you need in one place — from **homes, spawn, warps, TPA, economy, chat, staff tools, GUI menus, and more**.

## ✨ Features
- 🏠 Home System
- 📍 Spawn System
- 🔁 Warp System
- 📩 TPA / TPAccept / TPHere
- 💰 Economy Support
- 💬 Chat System
- 🛠 Staff & Admin Tools
- 🎮 Custom GUI Menus
- 🔌 PlaceholderAPI Support
- 💎 Vault Support
- ⚙️ Highly Configurable
